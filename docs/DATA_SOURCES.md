# مصادر البيانات في صَلِّها — Salliha

> قاعدة المشروع: لا يُستخدم الذكاء الاصطناعي كمصدر للنص القرآني أو الأذكار أو التفسير. دوره في هذا المشروع برمجي فقط: الفهرسة، البحث، الواجهة، التخزين، والاختبارات.

## القرآن الكريم

- **المصدر المضمّن:** `quran-json` الإصدار `3.1.2`.
- **الرابط:** https://www.npmjs.com/package/quran-json/v/3.1.2
- **المستند من المصدر:** يصرّح `quran-json` أن نص القرآن العثماني مأخوذ من **The Noble Qur'an Encyclopedia**، وأن الحزمة منشورة برخصة `CC-BY-4.0`.
- **ملف المصدر المحلي:** `data/sources/quran/quran-json-3.1.2-quran.json`
- **SHA-256:** `d8a8adff387f60ce3ff7dbe3238dd9b27120bfe29d8fcb07ad2e89cad37cefd4`
- **الاستخدام داخل التطبيق:** يتم توليد `src/data/quran/quran.generated.json` آليًا من ملف المصدر. التوليد لا يغيّر نص الآيات؛ يضيف فقط `surahId`, `surahName`, `ayahNumber`, `globalAyahNumber`, والموضع.
- **التحقق:** `npm run validate:quran` يقارن النص المولد بالنص الأصلي آية آية ويفشل عند أي اختلاف.

## التفسير

- **المصدر التشغيلي:** AlQuran.cloud API — إصدار تفسير `ar.muyassar`.
- **الرابط:** https://alquran.cloud/api
- **المعرّف:** `ar.muyassar`
- **اسم المصدر المعاد من API:** `تفسير الميسر — King Fahad Quran Complex`.
- **طريقة الاستخدام:** لا يتم توليد أو اختراع تفسير. عند ضغط المستخدم على "التفسير" يتم جلب النص من المصدر وعرض اسم المصدر والرابط. عند عدم توفر الإنترنت تظهر رسالة واضحة.
- **التخزين:** غير مضمّن Offline في هذه النسخة حتى تبقى شروط المحتوى والترخيص واضحة. يمكن إضافة نسخة Offline لاحقًا فقط بعد مراجعة إذن إعادة التوزيع الكامل.

## التلاوات والقراء

- **المصدر:** AlQuran.cloud / Islamic Network CDN.
- **الرابط:** https://alquran.cloud/terms-and-conditions
- **المعرّفات المبدئية:** `ar.alafasy`, `ar.abdulbasitmurattal`, `ar.husary`.
- **طريقة الاستخدام:** بث آيات من CDN حسب رقم الآية العالمي. Download Manager يحفظ الملفات داخل Cache الجهاز للاستخدام الشخصي Offline عندما يسمح المتصفح و CORS ومساحة التخزين.
- **ملاحظة ترخيص:** لا تُعاد استضافة ملفات التلاوة داخل المستودع ولا تُباع ولا توضع خلف Paywall.
